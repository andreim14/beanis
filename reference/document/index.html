    Document ¶

    Bases: LazyModel, SettersInterface, InheritanceInterface, OtherGettersInterface

    Document Mapping class for Redis.

    Uses Redis Hashes for storage by default, with support for secondary indexes, TTL, and batch operations.

    find_by_vector_similarity async classmethod ¶

    find_by_vector_similarity(query_vector: List[float], k: int = 10, field: Optional[str] = None, filter: Optional[str] = None, ef_runtime: Optional[int] = None) -> List[Tuple[str, float]]

    Nearest documents by vector similarity, as (id, similarity) pairs.

    Similarity is in [0, 1], higher is closer. filter is a Redis vector-set expression over the document's scalar fields, for example '.user_id == "u1"' or '.year >= 2024 and .lang == "it"'.
