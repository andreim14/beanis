    Fields and indexes¶

    Indexed ¶

    Indexed(field_type: Type, **kwargs) -> Type

    Helper function to create an indexed field

    Usage: class Product(Document): category: Indexed[str] # Set index price: Indexed[float] # Sorted Set index

    IndexedField ¶

    Marks a field as indexed for secondary index support

    Usage: class Product(Document): category: Annotated[str, IndexedField()] # Set index price: Annotated[float, IndexedField()] # Sorted Set index location: Annotated[GeoPoint, IndexedField()] # Geo index

    VectorField ¶

    VectorField(dimensions: Optional[int], algorithm: str = 'HNSW', distance_metric: str = 'COSINE', m: int = 16, ef_construction: int = 200, quantization: str = 'Q8') -> IndexedField

    A vector field stored in a Redis 8 vector set (VADD/VSIM), for similarity search with Document.vector_search.

    Usage::

    class Chunk(Document):
    embedding: Annotated[List[float], VectorField(dimensions=384)]

    Parameters:

    Name Type Description Default
    dimensions Optional[int]

    vector size, or None to take it from the first vector written

    		 required
    algorithm str

    only "HNSW" (vector sets have no other index)

    		 'HNSW'
    distance_metric str

    only "COSINE"

    		 'COSINE'
    m int

    HNSW connections per node

    		 16
    ef_construction int

    HNSW build-time search width

    		 200
    quantization str

    "Q8" (default, int8), "NOQUANT" (float32) or "BIN"

    		 'Q8'

    GeoPoint ¶

    Bases: BaseModel

    Represents a geographic point with longitude and latitude

    Usage: class Store(Document): name: str location: Indexed[GeoPoint] # Geo index

    store = Store(name="HQ", location=GeoPoint(longitude=-122.4, latitude=37.8))

    as_tuple ¶

    as_tuple() -> Tuple[float, float]

    Return (longitude, latitude) tuple for Redis GEOADD

    IndexManager ¶

    Manages secondary indexes for documents using Redis Sets and Sorted Sets

    find_by_geo_radius async staticmethod ¶

    find_by_geo_radius(redis_client, document_class: Type, field_name: str, longitude: float, latitude: float, radius: float, unit: str = 'km') -> List[str]

    Find document IDs within a radius of a geo location

    Parameters:

    Name Type Description Default
    field_name str

    Name of the geo-indexed field

    		 required
    longitude float

    Center point longitude

    		 required
    latitude float

    Center point latitude

    		 required
    radius float

    Search radius

    		 required
    unit str

    Distance unit - 'm', 'km', 'mi', 'ft' (default: 'km')

    Usage: nearby = await IndexManager.find_by_geo_radius( redis_client, Store, "location", longitude=-122.4, latitude=37.8, radius=10, unit="km" )

    		 'km'

    find_by_geo_radius_with_distance async staticmethod ¶

    find_by_geo_radius_with_distance(redis_client, document_class: Type, field_name: str, longitude: float, latitude: float, radius: float, unit: str = 'km') -> List[Tuple[str, float]]

    Find document IDs within a radius with their distances

    Returns list of (document_id, distance) tuples

    Usage: nearby = await IndexManager.find_by_geo_radius_with_distance( redis_client, Store, "location", longitude=-122.4, latitude=37.8, radius=10, unit="km" ) for doc_id, distance in nearby: print(f"{doc_id}: {distance} km away")
